# ☁️ Cloud Security & IAM Lab — Microsoft Azure

Laboratório prático de **Cloud Security, IAM e infraestrutura no Microsoft Azure**, desenvolvido de forma incremental conforme minha evolução técnica.

## 🎯 Objetivo

Aqui é onde aplico na prática meus conhecimentos de **Cloud Security, IAM e infraestrutura no Microsoft Azure**. Construo, testo e modifico o ambiente conforme avanço nos estudos, experimentando diferentes configurações e abordagens. Os desafios, erros, decisões e aprendizados relevantes fazem parte da evolução do laboratório e do meu desenvolvimento técnico.

## Laboratório

| Área | O que é tratado |

| 🌐 **[Rede](./02-rede/rede.md)** | VNet, subnets, NSGs, segmentação e controle de tráfego |
| 🔐 **[Controle de Acesso](./03-controle-acesso/controle-acesso.md)** | RBAC, MFA, Bastion, permissões e administração segura |

| 🛡️ **[Governança / Azure Policy](./06-governanca/azure-policy.md)** | Policies, enforcement, padrões e controles preventivos |
| 🔑 **07 — Federação / SSO** | Federação de identidade e Single Sign-On |
| 🔒 **08 — Criptografia** | Proteção de dados, Key Vault, secrets e criptografia |
| 🚨 **09 — Resposta a Incidentes** | Investigação, contenção, recuperação e resposta |
