# Laboratórios de Cibersegurança

>Ambientes práticos que desenvolvo para aplicar e consolidar conhecimentos em segurança da informação, infraestrutura, Cloud e Blue Team.

---

## 1. LAB 01 — Cloud Security | Microsoft Azure

Ambiente em nuvem construído passo a passo, buscando aplicar práticas de segurança próximas de um cenário corporativo.

**Foco:** Cloud Security, IAM, segmentação de rede, controle de acesso e hardening.

**Objetivo:** construir uma infraestrutura segura, reduzir a exposição dos recursos e validar os controles na prática.

**Stack:** Azure, VNet, NSGs, Windows Server, Jump Server e Microsoft Entra ID.

**Referências:** Microsoft Cloud Security, Zero Trust, CIS Controls, ISO 27001 e PCI DSS.

[Ver laboratório →](./laboratorio-cloudsecurity/)

---

## 2. LAB 02 — On-Premises | Blue Team

Ambiente corporativo local voltado à prática de monitoramento, detecção e resposta a eventos de segurança.

**Foco:** Blue Team, SOC, SIEM, análise de logs, detecção e resposta.

**Objetivo:** simular um ambiente corporativo e praticar a identificação e investigação de atividades suspeitas.

**Stack:** Wazuh, Graylog, TheHive, Active Directory e Sysmon.

**Referências:** MITRE ATT&CK, CIS Controls, NIST Cybersecurity Framework e boas práticas de SOC.
